# مهارة: طباعة الفواتير والسندات الحرارية (ESC/POS Thermal Printer)

تُستخدم هذه المهارة لتوجيه وتجهيز طباعة الفواتير وسندات القبض الميدانية عبر طابعات البلوتوث الحرارية المحمولة (قياس 58 ملم و 80 ملم) لتمكين المشغل من تسليم المزارع إشعاراً ورقياً فورياً عند انتهاء جلسة السقي أو استلام دفعة نقدية.

## 1. المعايير العامة للطباعة الحرارية الميدانية

1. **التعامل مع النصوص العربية والـ RTL في الطابعات الحرارية:**
   * الطابعات الحرارية تستقبل الأوامر بترميز ESC/POS؛ لذلك يجب تشكيل النصوص والكلمات العربية عبر مكتبة معالجة الحروف والـ Reshaping (`arabic_reshaper / bidi`) لضمان خروج الحروف متصلة وبالاتجاه الصحيح من اليمين لليسار.
2. **قياسات الورق المدعومة:**
   * **58mm (الأكثر شيوعاً ميدانياً):** العرض القياسي 32 حرفاً للسطر الواحد.
   * **80mm:** العرض القياسي 48 حرفاً للسطر الواحد.

## 2. هيكل وقالب فاتورة جلسة السقي المعتمد

يجب أن يحتوي الإيصال الورقي على البيانات الأساسية المرتبة كالتالي:

```text
================================
         بئر النور الحديث
     فاتورة جلسة سقي ومياه
================================
رقم الفاتورة: INV-20260825-001
التاريخ: 2026-08-25  الوقت: 10:30 ص
المشغل: خالد النجحي
المزارع: محمد عبدالله الشامي
الأرض: أرض الوادي
--------------------------------
تفاصيل التشغيل:
- البداية: 08:00 ص  النهاية: 10:00 ص
- المدة الإجمالية: 2 ساعة و 0 دقيقة
- مصدر الطاقة: طاقة شمسية
- سعر الساعة: 3,500 ريال
--------------------------------
المبلغ الإجمالي: 7,000 ريال يمني
المبلغ كتابة: سبعة آلاف ريال
--------------------------------
المدفوع نقداً: 7,000 ريال
المتبقي: 0 ريال
================================
       شكراً لتعاملكم معنا
================================
```

## 3. هيكل سند قبض دفعة نقدية

عند استلام دفعة نقدية مستقلة من المزارع:
* يطبع السند موضحاً: اسم المزارع، رقم السند، التاريخ، المبلغ بالأرقام والتفقيط بالريال اليمني، الرصيد السابق، والمتبقي الحالي بعد الدفعة، مع توقيع المشغل واسم البئر.

## 4. الممارسات الميدانية الآمنة

- **منع تكرار الطباعة غير المقصود:** وضع زر حماية يمنع إرسال أمر الطباعة مرتين متتاليتين في نفس الثانية.
- **الاستقلالية التامة عن الإنترنت:** توليد بيانات الإيصال وطباعته محلياً عبر البلوتوث دون اشتراط اتصال بالإنترنت.
