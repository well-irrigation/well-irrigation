# مهارة: معايير الواجهات المالية والتفقيط العربي (Arabic Financial UI Suite)

تُستخدم هذه المهارة لضبط وتوحيد كافة شاشات وحقول وعناصر عرض المبالغ المالية في تطبيق Flutter وفق أعلى المعايير العالمية المعتمدة في القرار **ق-119**.

## 1. المكونات المعيارية الإلزامية للمبالغ والأسعار

### أ. حقول إدخال المبالغ والأسعار (`CurrencyTextFormField`)
يجب استخدام مكوّن `CurrencyTextFormField` (من `core/widgets/currency_text_form_field.dart`) في أي حقل مالي يتطلب إدخال مبلغ أو سعر بالريال:
* **الفواصل الألفية اللحظية:** إضافة الفواصل تلقائياً مع الكتابة (`3,500` ، `100,000`).
* **التفقيط المالي العربي الحي:** إظهار شريط أنيق أسفل الحقل يعرض المبلغ كتابة باللغة العربية الفصيحة للريال اليمني لحظياً (مثل: `خمسمائة ألف ريال`).
* **توحيد الأرقام (0-9):** تحويل الأرقام المشرقية إلى إنجليزية لحظياً.
* **ضبط موضع المؤشر الذكي:** ثبات مؤشر الكتابة في مكانه الطبيعي عند إضافة الفواصل دون قفزات مزعجة.

### ب. عرض المبالغ الثابتة (`CurrencyDisplay`)
يجب استخدام `CurrencyDisplay` (من `core/widgets/currency_display.dart`) عند عرض أي مبالغ في البطاقات أو الفواتير أو التقارير:
* يعرض الرقم المنسق بالفواصل مع وحدة العملة (`ريال يمني`).
* يعرض التفقيط المالي كتابة تحته لسهولة القراءة السريعة وتأكيد دقة المبلغ.

## 2. قواعد التعامل مع الأرقام والعملة

1. **لا كسور ولا أعشار:** جميع المبالغ والأسعار تُعامل كأعداد صحيحة `int` بالريال اليمني الكامل.
2. **استخراج الأرقام الصافية:** استخدام `CurrencyUtils.parseRawInt(text)` لاستخراج العدد الصحيح الصافي وتجريد الفواصل قبل الحفظ.
3. **توحيد نصوص ومسميات العملة:**
   * الحقول: لاحقة الحقل تكون `ريال` أو `ريال / ساعة`.
   * الفواتير والتقارير: `ريال يمني`.
4. **التفقيط المالي الفصيح (`Tafqeet.format(amount)`):**
   * يدعم الوحدات من الآحاد حتى المليارات وفق قواعد التمييز والإعراب المالي اليمني:
     * `1` ← `ريال واحد`
     * `2` ← `ريالان`
     * `3` إلى `10` ← `ثلاثة ريالات` إلى `عشرة ريالات`
     * `11` فما فوق ← `أحد عشر ريالاً` .. `مائة ألف ريال` .. `مليون ريال`.

## 3. التغذية التفاعلية للمستخدم (Micro-Interactions & Feedback)

- **التغذية اللمسية (`HapticFeedback.selectionClick()`):** إعطاء اهتزاز خفيف جداً عند اكتمال الأرقام الصحيحة أو تأكيد الحفظ المالي.
- **التنبيهات الملونة للنسب والحصص:** تحول شريط التوزيع للون الأخضر عند وصول المجموع إلى 100%، وللأحمر عند التجاوز مع توضيح النسبة المتبقية بدقة.
