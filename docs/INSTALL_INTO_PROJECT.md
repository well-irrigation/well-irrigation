# كيف تنقل مجلد الوثائق إلى جهازك

**آخر تحديث:** 2026-08-12
**لمن:** المالك خالد النجحي — خطوات مباشرة بلا خبرة مسبقة

---

## أين توجد الملفات الآن

الملفات مكتوبة في **بيئة عمل مؤقتة** تابعة للمساعد، وليست على جهازك.
هذه البيئة **قد تُمسح في أي لحظة** (وقد حدث ذلك فعلًا مرة واحدة في 2026-08-12).

**القاعدة:** النسخة التي على **جهازك** هي النسخة الحقيقية. ما في بيئة المساعد مجرد نسخة عمل.

---

## الخطوات الخمس

### 1) حمّل الملف المضغوط

يُرسل في المحادثة بطاقة تحميل باسم `well-irrigation-docs.zip`. اضغط عليها.
حجمه نحو ميجابايت واحد، وينزل عادةً إلى مجلد `~/Downloads`.

### 2) أعد تسمية مجلد المشروع (القرار ق-41)

المسار القديم: `/home/kali/pr/well-management-platform`
المسار الجديد: `/home/kali/pr/well-irrigation`

```bash
cd /home/kali/pr
mv well-management-platform well-irrigation
```

### 3) فكّ الضغط داخل المشروع

```bash
cd /home/kali/pr/well-irrigation
unzip -o ~/Downloads/well-irrigation-docs.zip
```

هذا ينشئ مجلد `docs/` داخل المشروع مباشرة، بجانب مجلد `supabase/` الموجود.

إذا لم يكن `unzip` مثبتًا:

```bash
sudo apt install unzip
```

### 4) تأكد من النتيجة

```bash
find docs -type f | sort
```

يجب أن تظهر **19 ملفًا**: ملفان في الجذر، وأربعة في `reference/`، وستة في `memory/`، وخمسة في `technical/`، واثنان في `legal/`.

### 5) احفظها في Git

```bash
cd /home/kali/pr/well-irrigation
git add docs
git commit -m "docs: add project memory folder (47+ decisions, references, legal)"
```

هذا **أول Commit في المشروع**. من لحظته تصير كل نسخة محفوظة وقابلة للاسترجاع.

---

## طريقة بديلة إن تعذر التحميل

كل ملفات الذاكرة نصية بصيغة Markdown، أي يمكن طباعتها في المحادثة ونسخها يدويًا.
لكن هذا **غير موصى به** لسببين: الوثائق المرجعية الأربع وحدها نحو **11,900 سطر**، والنسخ اليدوي يفسد المحاذاة والرموز العربية.

---

## قاعدة دائمة من الآن

بعد كل جلسة عمل يُعدّل فيها مجلد `docs/`:

1. يُرسل ملف مضغوط جديد.
2. يُفك فوق القديم بالخيار `-o`.
3. يُعمل Commit جديد.

لا تُعدّل ملفات `docs/` يدويًا على جهازك وفي بيئة المساعد في الوقت نفسه، وإلا ضاع أحد التعديلين.
إن عدّلت شيئًا بنفسك، أخبر المساعد قبل الجلسة التالية.
