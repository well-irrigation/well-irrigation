# واجهة تعديل مبلغ الجلسة

**الحالة:** IMPLEMENTED + VERIFIED LOCAL + CI VERIFIED + DEVICE ACCEPTANCE
PENDING. الواجهة واختباراتها مدفوعة في PR #68؛ لا سجل جهاز بعد. عقد الخادم:
`MANUAL_SESSION_FINANCIAL_ADJUSTMENT_SERVER.md`، والنواة:
`MANUAL_SESSION_FINANCIAL_ADJUSTMENT_MOBILE_CORE.md`.

يظهر «تعديل المبلغ» بجوار تفاصيل السداد في تفاصيل الجلسة المكتملة بعد تحقق
قدرة الخادم. يعاد جلب الحالة المالية عند فتح صفحة التعديل. يعرض تعذر
القراءة إعادة تحميل، وتظهر أسباب القفل والمراجعة برسائل مفهومة. تستخدم
الجلسة اليدوية المكتملة المسار نفسه. يمرّر ملف المزارع معرّفي الحساب والبئر
إلى تفاصيل الجلسة، فتُقرأ الأهلية من الخادم بالطريقة نفسها عند فتحها من
ملف المزارع أو سجل الجلسات.

تعرض الصفحة المبلغ المحسوب والمعتمد حاليًا والمدفوع والمتبقي من حقول الحالة
الخادمية. تظهر القيمة الأصلية المختلفة ضمن «المزيد من التفاصيل»، ويعرض
«سجل تعديلات المبلغ» السابق والمعتمد والسبب واسم الفاعل والوقت. تظهر القيمة
المفقودة بعبارة «غير متاح». تُعرض الأرقام كاملة مع التفاف النص.

الحقل مخصص للريال اليمني الصحيح. يبقى النص المدخل ظاهرًا كما كتبه المستخدم.
يحول المحلل الأرقام العربية والفارسية إلى أرقام غربية ويتحقق من كامل الصيغة
قبل إزالة فواصل آلاف صحيحة. يقبل الصفر وحد bigint الأعلى ويرفض الإشارات
والكسور والنص المختلط والتجميع المشوه. مكونات العملة المشتركة مستقلة عن هذا
الحقل. تُملأ القيمة الحالية أولًا، ويُطلب تغييرها في الحالة العادية. يمكن
إعادة اعتماد القيمة نفسها عندما يسمح الخادم بالتعديل أثناء المراجعة المالية.

تطلب «مراجعة التعديل» سببًا غير فارغ وتعرض الحالي والجديد والسبب في نافذة
تأكيد واحدة. يوضح النص أن الإجراء لا يسجل دفعة، ويبرز اعتماد الصفر عند
اختياره. يرتبط التأكيد بكائن الحالة المقروءة ومراجعاته الثلاث. التحديث
الصريح يستبدل اللقطة ويتطلب مراجعة جديدة. تحفظ الموافقة طلبًا واحدًا في
الطابور القائم، ويمكن مغادرة الصفحة بعد الحفظ حتى عند انقطاع الاتصال.
تحميل حالة خادمية صحيحة شرط لفتح النموذج.

يُقرأ المانع المحلي عند الفتح وقبل نافذة التأكيد وبعد الموافقة، وتظهر حالة
الطلب المتين بدل النموذج إذا وجد مانع. تحمل متابعة الطلب المحدد هويته
المحلية عبر إعادة الفتح. تعيد الشاشة قراءة الطلب المحلي المعلّق أو الجاري
إرساله أو قيد المعالجة كل ثانيتين بعد اكتمال القراءة السابقة، ما دامت تملك
المسار الحالي. تتوقف مؤقتًا إذا غطّاها مسار آخر أو بدأت إيماءة الرجوع،
وتستأنف عند عودة المسار أو إلغاء الإيماءة. تتوقف عند المغادرة أو تبدّل السياق،
وعند القبول أو عدم اليقين أو تعذّر القراءة أو تعدد الطلبات أو نتيجة مراجعة
نهائية. «متابعة الحالة» تبقى قراءة محلية من العقد النوعي، وتبطل أي نتيجة
أقدم. المزامنة واستعادة الإيصال مسؤولية النواة. قراءتا المتابعة التلقائية
واليدوية لا تستدعيان تقديم التعديل أو طلب الإيصال من الخادم. عدم العثور على الإيصال أو عدم
اليقين أو فساد الدليل أو تعدد الطلبات يوقف إنشاء بديل. تعارض المراجعات
يحتاج قراءة حديثة ومراجعة وتأكيدًا جديدين. تعارض هوية الطلب يبقى رسالة
متابعة مستقلة. نتائج الرفض والقفل والمنع لها رسائل عربية مخصصة.

قد تلاحظ الصفحة اعتمادًا محفوظًا أثناء إيماءة الرجوع أو بينما يغطيها مسار
آخر. تحتفظ بالاعتماد حتى تستعيد ملكية المسار، ثم تعود إلى التفاصيل مرة
واحدة وتطلب تحديثها من الخادم. لا تتطلب إيماءة الرجوع الملغاة قراءة متابعة
أخرى. عند المغادرة الفعلية يبقى الاعتماد محفوظًا ولا يحدث تنقّل متأخر.
يعرض نجاح الاعتماد مستقلًا عن نتيجة تحديث التفاصيل. تمنع ملكية المسار
وأجيال القراءة تطبيق الاستجابات المتأخرة على سياق آخر.
