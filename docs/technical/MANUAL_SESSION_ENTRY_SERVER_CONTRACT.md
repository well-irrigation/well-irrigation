# عقود إدخال جلسة سقي منفذة خارج التطبيق

الحالة: IMPLEMENTED + VERIFIED LOCAL؛ العقد والاختبارات الدائمة محفوظة
في الفرع المحلي غير المدفوع، ولم تُنشر الهجرات سحابيًا. أساس المنشأ في
`f7eab60`، والتحقق المحلي المالك موثق في وثيقة النواة والواجهة. لا هاتف
أو UI داخل هذه الشريحة، ولا تجاوز مالي فيها.

## السطح العام

- api.record_historical_session(p_well_id uuid,p_command_id uuid,p_request jsonb)
- api.adopt_external_session(p_well_id uuid,p_command_id uuid,p_request jsonb)
- api.get_manual_session_entry_receipt(p_well_id uuid,p_command_id uuid)
- api.get_manual_session_entry_capability(p_well_id uuid)

كلها SECURITY INVOKER. الأغلفة الداخلية الممنوحة تتحقق من auth.uid() والتعيين
النشط وصلاحية session.manual_entry. ربط القدرة: tenant_owner وwell_manager
وoperator وفق خريطة الأدوار القائمة؛ session.correct لا تمنح إنشاءً.
يبقى شرط session.start، وsession.complete للمنتهية، نافذًا من الأساس المشترك.

## الطلب

JSON object بإصدار version=1، وpump_id وfarm_id وfarmer_well_account_id،
وstarted_at بصيغة ISO صريحة مع إزاحة، وenergy_source، وreason غير فارغ.
للمنتهية ended_at إلزامية؛ للجارية لا تُقبل ended_at.
notes نص اختياري. crops مصفوفة نصوص اختيارية. fuel_owner_person_id اختياري
لمصدر farmer_diesel فقط. للمنتهية يمكن fuel_quantity_ml موجبة و
fuel_measurement_type actual/estimated وfuel_tank_id؛ كمية well_diesel
تحتاج خزانًا صالحًا. لا إعادة بناء للأحداث القديمة.
أي مفتاح غير مدعوم، بما فيه booking_id وactor_id والمبلغ، يُرفض.
لا حد عمر؛ يلزم ثبوت السعر التاريخي وصحة الوقت والنطاق.

تُثبت الأزمنة كقيم UTC والحقول الاختيارية بقيمها القانونية الافتراضية قبل
مقارنة هوية الأمر. اختلاف كتابة الإزاحة للحظة نفسها ليس اختلاف وقائع؛
تغيير الوقائع/السبب/الملاحظات تحت الهوية نفسها يتعارض ولا يعيد الكتابة.

## التنفيذ والمال

القفل: جذر المال ثم البئر ثم حجز الأمر. المنتهية تُنشأ مغلقة عبر النواة
النهائية في الأساس، وليست بدءًا عاديًا مؤقتًا. المقطع يغلق ثم يستدعي
finalize_session_from_closed_segments نفسه. لا نسخة من حساب الإكمال.
الجارية تُدرج مفتوحة تحت المنشأ المثبت ثم تُلتقط لقطة سعرها ومقطعها الأول.
كلاهما بلا booking_id أو وردية أو محصّل حالي.

create_manual_entry_priced_segment يعزل اختيار اللقطة لهذا المدخل؛ يحتفظ
بقواعد المقطع والملكية القائمة ويشمل الجداول active وexpired التي يغطي
نطاقها وقت الحدث. لا draft/cancelled. المسارات القديمة لا تتغير.
البديل الإرثي billing.well_pricing يُقرأ عند وقت الحدث، وليس بسعر اليوم.
غياب الدليل يؤدي needs_review مع تراجع كل الماديّة. مبلغ الرسم المحسوب
محفوظ كأصل يمكن لتسوية مالية مدققة مستقبلية الرجوع إليه.

## النتائج والاسترداد

accepted: النتيجة القانونية التاريخية المحفوظة، وليست ادعاءً بحالة مالية
حالية بعد أي تصحيح لاحق. processing: حجز موجود لا يجيز كتابة ثانية.
conflict_overlap وconflict_active_resource حالتا تعارض أعمال مستقلتان.
validation_error لطلب غير صالح/متغير. needs_review لنقص إثبات السعر أو
الموارد/تغير الإذن. unresolved لفشل مؤقت غير محسوم دون تفاصيل تقنية عامة.

نتائج التعارض/المراجعة/الفشل تحفظ في سجل الأمر دون جلسة جزئية؛ إعادة الطلب
المطابق تسترد النتيجة نفسها. معالجة المستخدم بتفاصيل جديدة تحتاج هوية
طلب جديدة، ولا يغير ذلك نتيجة الأمر الأول. التحقق الأولي الذي يرفض شكل
الطلب قبل الحجز لا ينشئ أمرًا.

الإيصال يتحقق من المصادقة والصلاحية قبل البحث. هوية tenant/well/command
ونوع الأمر والطلب والنتيجة وروابط المنشأ المقبول مطابقة. لا أثر كتابي.
not_found وunresolved لا يمنحان retry_authorized؛ الحقل false دائمًا.
الإيصال الأصلي للجارية يبقى ثابتًا بعد إكمالها أو تصحيحها لاحقًا.
