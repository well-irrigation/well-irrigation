# Well Management Platform

منصة تجارية متعددة المستأجرين لإدارة وتشغيل ومحاسبة آبار المياه والري.

## المرحلة الحالية

يتم حاليًا بناء الأساس التقني للمشروع، ويشمل:

- بيئة Supabase محلية
- قاعدة بيانات PostgreSQL
- نظام المستأجرين والصلاحيات
- إدارة الأشخاص والمزارعين والشركاء
- إدارة الآبار ومصادر الطاقة
- محرك الفوترة والمحاسبة
- تطبيق Android يعمل دون اتصال

## بنية المشروع

- `apps/mobile` — تطبيق الهاتف
- `apps/admin-web` — لوحة الإدارة
- `packages/business_rules` — قواعد العمل المشتركة
- `packages/financial_engine` — المحرك المالي
- `supabase/migrations` — ترحيلات قاعدة البيانات
- `supabase/tests` — اختبارات قاعدة البيانات
- `docs` — الوثائق التقنية والمعمارية
- `scripts` — أدوات المشروع
